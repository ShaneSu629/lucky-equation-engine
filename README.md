# 🎲 幸运方程式 · 数字推理引擎 v2.0

一个集成了**历史数据自动同步**、**走势分析**、**多维算法推理**、**AI 大模型深度分析**、**集成推理（贝叶斯+蒙特卡洛+马尔可夫）**，以及**组合优化策略**的数字娱乐交互平台。

> **v2.0 更新**（2026-07-26）：全面升级推理引擎，集成 2025-2026 年最新算法研究成果。

---

## 🛠️ 技术框架与依赖

项目采用现代 Python 生态链构建，实现了轻量、高效的数据处理与交互展示：

- **前端交互框架**: `Streamlit` — 提供响应式、低延迟的 Web 交互界面及动态控制面板。
- **数据处理引擎**: `Pandas` / `NumPy` — 用于高效清洗、归档、聚合分析及矩阵运算。
- **可视化**: `Plotly` — 置信度分布柱状图等交互式图表。
- **网络请求模块**: `Requests` — 负责增量或全量拉取第三方彩票历史开奖数据接口。
- **人工智能核心**: `OpenAI SDK` — 完美兼容主流大语言模型（如 SiliconFlow 平台部署的 `DeepSeek-R1`、`通义千问`等），实现深度逻辑推理和策略优化。

## 🌟 核心功能介绍

### 1. 📈 历史数据看板 & 走势分析

- **智能同步机制**：支持首次全量同步（抓取数十载完整历史开奖）与后续秒级增量同步，本地 CSV 异步归档。
- **多维度看板**：动态展示历史开奖明细表格，通过柱状图与热力图实时呈现高频/低频号码分布。

### 2. 🎯 下期智能号码预测 (v2.0 增强)

- **五种算法协同预测**：指数衰减加权 + 马尔可夫转移矩阵 + 遗漏回补概率 + 贝叶斯融合 + 蒙特卡洛模拟。
- **多维数学约束校验**：AC 值、跨度、012 路、质合比、尾数分布、奇偶比、三区分布等多维自动过滤。
- **双色球**：红球采用四维加权（频率+衰减+遗漏+马尔可夫）均衡抽取，蓝球独立建模。
- **快乐8（选十）**：采用加权热温冷占比例学抽选。
- **福彩3D**：百、十、个位独立进行衰减加权 + 马尔可夫转移 + 遗漏回补分析。

### 3. 🧬 集成预测模式 (NEW)

- **三路投票机制**：贝叶斯融合(40%) + 蒙特卡洛(30%) + 马尔可夫链(30%) 三方投票。
- **10,000 次蒙特卡洛模拟**：基于融合概率进行大规模无放回抽样。
- **置信度可视化**：Plotly 柱状图展示号码置信度分布，红（≥30%高置信）/ 橙（≥15%中置信）/ 灰。

### 4. 🤖 AI 智能深度预测 (v2.0 提示词升级)

- **15 维特征工程**：在原有基础上新增 AC 值趋势、跨度分布、012 路分布、质合比、尾数分布、大小比、指数衰减频率 TOP15、龙头凤尾定位等。
- **增强约束提示词**：10 项数学约束指导 AI 产出更合理的号码组合。
- **贝叶斯融合权重注入**：将增强引擎的融合结果、回补概率、马尔可夫转移概率、蒙特卡洛置信度注入提示词。

### 5. 🛡️ 组合优化与配比策略

- 用户输入计划注数，系统自动通过数学期望计算，匹配不同玩法的最优组合配比，降低本金归零风险。
- **AI 策略优化**：由 AI 大模型智能推荐"保守/平衡/激进"组合方案，生成优化报告。

## 🧮 核心算法解析 (v2.0)

### 1. 📉 指数衰减加权频率 (Exponential Decay Weighting)

近期开奖数据比远期数据有更高的参考价值。权重公式：

$$\text{weight}_i = 0.95^{\text{position}}$$

position=0 为最新一期（权重 1.0），position=N 为最早一期（权重趋近 0）。所有号码的加权频次归一化为概率分布。

### 2. 🔗 一阶马尔可夫转移矩阵 (Markov Chain Transition)

构建号码级别的转移矩阵，计算条件概率 $P(\text{num}_j \mid \text{num}_i)$ = 上期出现号码 $i$ 后下期出现号码 $j$ 的历史概率。基于上期开奖号码，对所有号码的下期出现概率进行加权平均。

### 3. 🔄 遗漏回补概率 (Cold Number Bounce Probability)

对每个号码计算：

- **current_gap**：当前已遗漏期数
- **max_gap**：历史最大遗漏期数
- **回补概率**：$\text{bounce\_prob} = \frac{\text{current\_gap}}{\text{max\_gap}}$

越接近历史最大遗漏值，回补概率越高（上限 95%）。

### 4. 🧬 贝叶斯融合权重 (Bayesian Fusion Weights)

在概率空间中对四个独立信号进行加权融合：

$$\text{score} = \exp(w_f \cdot \ln(\text{freq}) + w_d \cdot \ln(\text{decay}) + w_m \cdot \ln(\text{bounce}) + w_k \cdot \ln(\text{markov}))$$

默认权重：衰减 30%、遗漏回补 25%、马尔可夫 25%、频率 20%。

### 5. 🎲 蒙特卡洛集成模拟 (Monte Carlo Ensemble)

基于贝叶斯融合概率分布，进行 10,000 次无放回加权抽样，统计每个号码在模拟中被选中的频率作为蒙特卡洛置信度。

### 6. 📏 多维数学约束校验器

对生成的红球组合进行自动质量检测：

| 约束维度  | 检验标准            |
| ----- | --------------- |
| AC 值  | 3-7（理想 4-6）     |
| 跨度    | 15-32（理想 18-30） |
| 奇偶比   | 2:4 / 3:3 / 4:2 |
| 012 路 | 不能有路数 ≥ 5 或 = 0 |
| 质合比   | 1:5 ~ 4:2       |
| 尾数    | ≥ 4 种不同尾数       |
| 三区分布  | 不能有区 ≥ 5 或 = 0  |

### 7. 🌡️ 热温冷划分算法 (经典算法保留)

根据号码在指定历史周期内的出现频次进行排序：

- **热码 (Hot)**：出现频次最高的前 33%
- **冷码 (Cold)**：出现频次最低的 33%
- **温码 (Warm)**：频次介于两者之间的 34%

## ⚙️ 快速使用说明 (本地运行)

### 第一步：安装 Python

请确保您的电脑上安装了 **Python 3.10 或更高版本** (推荐 3.11 或 3.12)。

### 第二步：安装所需依赖

在项目根目录下打开终端，运行：

```bash
pip install -r requirements.txt
```

### 第三步：一键启动应用

- **Windows 用户**: 直接双击运行 **`start.bat`** 即可。
- **macOS / Linux 用户**: 在终端中运行 `sh start.sh`。

首次打开后，请前往侧边栏点击**「🔄 立即同步最新数据」**进行本地数据库初始化。

### 第四步：体验新功能

- **集成预测**：在「智能号码预测」页面，滑动到「🧬 集成预测」区域，选择彩种，点击运行即可看到三路投票的置信度分布图和推荐号码。
- **算法说明**：可参考本文档的「核心算法解析」部分了解算法原理。
